# VPN Bypass

Небольшая утилита для Windows, которая открывает выбранные сайты через обычное интернет-соединение, пока остальной трафик продолжает идти через VPN.

Например, можно оставить VPN включённым, но добавить в исключения сайт, который с ним не работает.

## Скачать

[Скачать последнюю версию VpnBypass.exe](https://github.com/VibeDearPepper/vpn-bypass/releases/latest/download/VpnBypass.exe)

Установка не нужна: сохраните файл в отдельную папку, запустите его и подтвердите запрос Windows. SmartScreen может показать предупреждение, потому что приложение не подписано платным сертификатом.

## Как пользоваться

1. Запустите `VpnBypass.exe` от имени администратора.
2. Добавьте домен или ссылку, например `example.com`.
3. Проверьте выбранный интернет-шлюз.
4. Нажмите «Обновить», если маршрут не появился сразу.

Программа сама обновляет IP-адреса сайтов и восстанавливает пропавшие маршруты. Маршруты временные: после перезагрузки Windows они исчезают и будут созданы заново при следующем запуске.

## Совместимость

- Работает только в Windows и требует права администратора.
- Поддерживает IPv4. IPv6 может продолжать идти через VPN.
- Не привязана к конкретному VPN, поэтому работает со многими VPN-клиентами.
- Может не сработать, если в VPN включён kill switch или он полностью блокирует трафик в обход туннеля.
- На macOS, Linux, Android и iOS эта версия не работает.

Поддержку любого VPN гарантировать нельзя: разные клиенты по-разному управляют маршрутами и сетевыми фильтрами.

## Приватность

Список сайтов, найденные IP-адреса и настройки шлюза хранятся только в локальном файле `sites.json`. Этот файл исключён из репозитория и не попадает в создаваемые архивы.

## Для разработчиков

- `src/Program.cs` — основной код приложения;
- `src/Packager.cs` — создание ZIP-архива;
- `src/app.manifest` — запрос прав администратора через UAC;
- `CreateArchive.exe` — готовый архиватор.
