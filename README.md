# VPN Bypass

Нативное Windows-приложение с графическим интерфейсом для направления выбранных сайтов через обычное интернет-соединение в обход активного VPN.

## Скачать

[Скачать последнюю версию VpnBypass.exe](https://github.com/VibeDearPepper/vpn-bypass/releases/latest/download/VpnBypass.exe)

Сохраните EXE в отдельную папку и запустите его. Приложение не требует установки. Windows может показать предупреждение SmartScreen, поскольку сборка не подписана коммерческим сертификатом.

## Запуск

Откройте `VpnBypass.exe` и подтвердите запрос UAC. Консоль, CMD и PowerShell для работы приложения не нужны.

В окне приложения можно:

- добавлять домены и полные HTTP/HTTPS-ссылки;
- видеть найденные IPv4-адреса и фактическое состояние маршрута;
- включать и отключать выбранное исключение;
- полностью удалять исключение вместе с его маршрутами;
- отключать сразу все исключения;
- выбирать физический интернет-шлюз;
- автоматически восстанавливать пропавшие маршруты раз в минуту.

Статус активных маршрутов обновляется каждые пять секунд. Маршруты временные и исчезают после перезагрузки Windows; при следующем запуске приложение восстановит включённые исключения.

## Файлы

- `VpnBypass.exe` — готовое приложение;
- `CreateArchive.exe` — создаёт чистый ZIP для передачи другим пользователям;
- `sites.json` — локальные настройки, которые создаются при запуске и не публикуются;
- `src/Program.cs` — исходный код;
- `src/app.manifest` — запрос прав администратора через UAC.

## Как поделиться программой

Запустите `CreateArchive.exe`. Он создаст готовый ZIP в папке `releases`.

В архив попадут только приложение, инструкция и краткий файл запуска. Ваш `sites.json`, список доменов, найденные IP-адреса и сведения о локальном шлюзе намеренно не архивируются.

## Ограничения

- Поддерживается IPv4. IPv6-трафик приложение не перенаправляет.
- DNS-запросы могут продолжать идти через VPN.
- Исключённый сайт видит обычный публичный IP-адрес пользователя.
- Приложение не создаёт постоянные маршруты.
